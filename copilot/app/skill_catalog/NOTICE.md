# Mitgelieferte Skills

Die Ordner `frontend-design` und `internal-comms` sind unveränderte Kopien aus dem Repository
https://github.com/anthropics/skills (Stand: Commit ca45fc4), Copyright Anthropic, PBC, lizenziert unter der
Apache License 2.0. Der Lizenztext liegt in jedem Ordner als `LICENSE.txt`.

Nicht mitgeliefert wird `doc-coauthoring` aus demselben Repository: Dafür liegt dort keine Lizenzdatei.
Die Dateien Word, PowerPoint, Excel und PDF desselben Repositorys stehen unter einer eigenen, nicht freien Lizenz und sind ebenfalls nicht enthalten.

Neue Einträge kommen in `catalog.json`; `tests/test_skills.py` prüft, dass jeder Eintrag eine Lizenzdatei, eine Quelle und beide Sprachen hat.
