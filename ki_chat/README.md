# KI Chat

Claude als eigener Chat in Home Assistant: Live-Antworten, getrennte Chats pro Benutzer mit Suche und Export, Projekte, Dateianhänge bis 50 MB, Dateien erzeugen (Word, Excel, PowerPoint, PDF, Skripte), Zugriff auf Home Assistant mit Rechtestufen, GitHub-Anbindung, Websuche, geplante Aufgaben, Projektwissen zum Hochladen und ein Gedächtnis je Haushalt und Person. Optional mit eigener Domain.

Du brauchst eigene Zugangsdaten zu Claude (API-Schlüssel oder, nur für den persönlichen Gebrauch, ein Abo-Token). Siehe die Registerkarte **Dokumentation**.
